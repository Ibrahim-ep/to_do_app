# ✅ To-Do App

A modern cross-platform **To-Do List** application built with **Flutter**. The app helps users organise their daily tasks through a clean and intuitive interface. Users can easily create, edit, complete, and delete tasks to stay productive and organised.

---

## ✨ Features

- ✅ Create new tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 📱 Responsive and user-friendly interface
- ♻️ Reusable Flutter widgets
- 📂 Clean and maintainable project structure
- ⚡ Smooth navigation and interactions

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android Emulator or Physical Device

### Installation

Clone the repository:

```bash
git clone https://github.com/Ibrahim-ep/to_do_app.git
```

Navigate to the project directory:

```bash
cd to_do_app
```

Install the dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
